Boot.dev AI Agent program design Practice.

## How to use
type: uv run main.py ""
Inbetween the quotes, type your prompt.

This is a 'toy' agent build for Boot.dev's AI agent project.
It does not possess the safeguards a proper agent would have.
Please use responsibly and take care about what files you give
it access to, if you take and use it yourself.
